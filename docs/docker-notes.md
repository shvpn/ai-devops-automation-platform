## What is docker?
A service or software that help you manage the same environment for easy deployment.
## What is docker file?
It is a blueprint to run and build a docker image
## What is docker image?
It is a readonly bulueprint to run and create container
## What is contailner?
It is the environment that contain your app can run.
## What is port mapping?
It is the method that allow the outside network communicate with the network inside contailner since it is the isolate lightweight environment.eg "8080:5000" when you acces prot 8080 it will fetch the port 5000 in your container.
